Interior Gateway Protocol Fundamentals — Lab 19-1

One network, two routing protocols, five routers.

IP addressing is already done. Your job is to run RIPv2 across the whole network, then run EIGRP AS 100 across the same network and watch which routes win. Everything on this bench — every command, output, metric and answer — comes from the five source decks listed at the bottom of the page.

The addressing you inherit pre-configured

What the lab asks for

  • Enable RIPv2 everywhere; advertise every network except 203.0.113.0/24 at first; no summarisation.
  • Add 203.0.113.0/24 to RIP on R4, but keep internal routes away from the Service Provider at 203.0.113.2.
  • Static default route on R4 to 203.0.113.2, then inject it into RIP so everyone learns the Internet.
  • Enable EIGRP AS 100 everywhere for the 10.x networks, then compare the two protocols in the routing table.

The one number that decides it

EIGRP internal
Administrative Distance 90
EIGRP external
Administrative Distance 170
RIP
Administrative Distance 120

Both protocols advertise the 10.x.x.x networks. EIGRP's lower AD of 90 beats RIP's 120, so the D routes get installed. Only RIP carries 203.0.113.0/24 and the default route, so those stay R and R*.
